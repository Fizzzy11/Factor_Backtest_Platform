# 外部收益与取数配置说明

## 外部收益数据

默认情况下，框架使用内置的 1D、5D、10D、20D open-to-open 未来收益：

```text
1D  = open[t+2]  / open[t+1]  - 1
5D  = open[t+6]  / open[t+1]  - 1
10D = open[t+11] / open[t+1]  - 1
20D = open[t+21] / open[t+1]  - 1
```

如果传入 `external_returns`，外部收益会作为额外收益标签，和内置 1D/5D/10D/20D 同级参与完整流程：

```text
IC configured by ic_methods
Cumulative IC
IC statistics
20-Day Moving Average IC
10-group return summary
layered group return
long-short return
performance metrics
artifacts
HTML report
```

默认 `ic_methods=["spearman"]` 时，上面的 IC 就是 Spearman RankIC。配置 `ic_methods=["pearson"]` 会输出 Pearson IC；配置 `ic_methods=["spearman", "pearson"]` 会同时输出两套 IC 表和图。

外部收益支持宽表：

```text
index = trade_date
columns = symbol
value = external return
```

CSV 宽表也可以使用显式日期列：

```text
date/trade_date, 000001.XSHE, 000002.XSHE, ...
```

框架会自动将 `date` 或 `trade_date` 列作为 `trade_date` index。这个口径与 v2.2.2 后的因子 CSV 宽表读取保持一致，避免显式日期列被误当作普通股票列。

也支持长表：

```text
trade_date/date + symbol/asset + return/ret/future_return/value/factor_value/factor
```

最重要的日期口径是：

```text
external_return.loc[t, symbol]
必须表示用于检验 factor_df.loc[t, symbol] 的未来收益标签。
```

这里的 `trade_date=t` 是因子日期，不是收益开始日，也不是收益结束日。比如 `2026-05-15` 这一行，应该和 `factor_df.loc["2026-05-15"]` 做 IC、分组收益和多空收益计算。

基本用法：

```python
result = run_factor_backtest(
    factor_df=factor_df,
    market_data=market_data,
    config=cfg,
    external_returns={
        "external_alpha": external_return_df,
    },
)
```

如果外部收益来自文件，可以直接传入路径：

```python
external_returns = {
    "external_5d": "/data/zhangyuan/external_returns/external_5d.csv",
}
```

如果外部收益需要绘制 10 组累计收益线，可以传入 `horizon_days`：

```python
external_returns = {
    "external_5d": {
        "data": external_return_df,
        "horizon_days": 5,
    },
}
```

`horizon_days` 不影响 IC、分组平均收益、多空收益等核心统计。它只影响 `10-Group Cumulative Return` 线图。

如果不传 `horizon_days`：

- 仍然计算所有表格型统计和多空序列。
- 不绘制该外部收益的 10 组累计收益线图。
- report 和模块 warning 会提示该收益标签缺少 `horizon_days`，已跳过累计收益线，避免未知周期收益被错误复利。

如果传入 `horizon_days`，累计线会先做日等价转换：

```python
daily_equivalent = (1 + group_return) ** (1 / horizon_days) - 1
```

再生成 10 组累计净值线。

如果只想使用外部收益，不计算内置 1D/5D/10D/20D，可以在配置里把 `horizons` 设为空列表：

```python
cfg = BacktestConfig(
    horizons=[],
    ic_methods=["spearman"],
)

result = run_factor_backtest(
    factor_df=factor_df,
    market_data=market_data,
    config=cfg,
    external_returns={
        "my_return": {
            "data": external_return_df,
            "horizon_days": 5,
        },
    },
)
```

当前接口仍需要传入 `market_data`，因为框架还会用行情日期和股票列做对齐、股票池和可交易性过滤。

## 取数配置集中化

当前框架仍然是混合取数：

- 行情、ST、停牌等已入库数据通过 ClickHouse 读取。
- 指数成分股 pool 暂时通过 CSV 读取。
- 因子值长期保留文件和数据库双入口：新因子可以继续用文件，已入库因子后续可以接数据库。
- 风格暴露和行业 dummy 当前通过本地 parquet/csv 文件读取，后续预留 ClickHouse 入口。

后续引用数据全部入库后，优先修改集中配置，而不是在计算逻辑里改路径或 SQL。

集中配置入口在 `factor_backtest_platform.config`：

ClickHouse 连接信息通过以下环境变量注入，不应写入源码、文档或版本库：

```text
FACTOR_BACKTEST_PLATFORM_CLICKHOUSE_HOST
FACTOR_BACKTEST_PLATFORM_CLICKHOUSE_PORT
FACTOR_BACKTEST_PLATFORM_CLICKHOUSE_USERNAME
FACTOR_BACKTEST_PLATFORM_CLICKHOUSE_PASSWORD
```

迁移期间继续兼容 `FACTOR_BACKTEST_CLICKHOUSE_*` 旧变量；若新旧变量同时存在，以 `FACTOR_BACKTEST_PLATFORM_CLICKHOUSE_*` 为准。

默认值为 `localhost:8123`、用户 `default` 和空密码。框架不会自动加载 `.env`；部署时应由凭据系统或进程启动脚本注入。

```python
from factor_backtest_platform import BacktestConfig
from factor_backtest_platform.config import ClickHouseConfig, ClickHouseTableConfig, DataSourceConfig, PathConfig

cfg = BacktestConfig(
    paths=PathConfig(
        project_dir="/app/workspace/zhangyuan/Factor_Backtest_Platform",
        data_root="/data/zhangyuan",
        pool_dir="/data/zhangyuan/pool",
        risk_exposure_path="risk&industry/CNE5_Industry_daily.parquet",
    ),
    data_sources=DataSourceConfig(
        market_data_source="clickhouse",
        pool_source="csv",
        factor_source="file",
        risk_exposure_source="csv",
        clickhouse=ClickHouseConfig(),
        clickhouse_tables=ClickHouseTableConfig(
            ohlcv="stock_data.view_stock_qfq_adjusted_ohlcv_v2",
            shares="cn_stock_fundamentals.shares",
            st="cn_stock_fundamentals.is_st_stock",
            suspended="cn_stock_fundamentals.is_suspended",
            risk_exposure=None,
        ),
    ),
)
```

现阶段 `pool_source="csv"` 和 `risk_exposure_source="csv"` 是已实现路径；其中 `risk_exposure_source="csv"` 为历史命名的本地文件入口，支持 parquet/csv，默认 parquet 读取依赖 `pyarrow`。`pool_source="clickhouse"` 和 `risk_exposure_source="clickhouse"` 是未来入库后的统一切换入口，目前会明确报未实现。ClickHouse 表名通过 `ClickHouseTableConfig` 统一维护，连接参数通过 `ClickHouseConfig` 统一维护。

读取 ClickHouse 行情时可以直接传入集中配置：

```python
market_data = load_market_data_from_clickhouse(
    start_date="2020-01-01",
    end_date="2026-05-02",
    config=cfg.data_sources,
)
```
